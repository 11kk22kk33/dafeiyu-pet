# 给接入 AI 的说明（先读这份）

> 详细版见同目录 README-AI.md（9333 字节，含目录结构、链路与验证清单）；本文件只做 3 分钟速览。

## 这个项目是什么
跑在 Windows 本机的 AI 宠物系统。核心是 proxy.py（8787，OpenAI 兼容网关），
把人设、记忆、权限、防抖、情绪拼进请求再转发给模型。QQ 消息经
SnowLuma(3000) → AstrBot(6185) → proxy(8787) 进来。桌宠与鱼搭子是可选前端。

## 重要边界（先记牢）
1. 桌面挂件与鱼搭子来自开源项目 Yuuyuko-uu/dsh-fish-buddy（许可 1.2），
   派生版必须保留原作者署名、禁止称自研。
2. config-paths.json 只放 17 个外部程序的路径；key.txt 只放模型密钥。
   两者都不含 QQ 号/群号/聊天记录。
3. 线上运行目录与工作区副本是两回事。改工作区不影响线上；要切换是显式动作。

## 怎么知道代码缺什么 / 被改过什么
按这个顺序对账（只出报告，不改）：
1. 备份对方现有代码，不在原文件上比对。
2. 比文件清单：本包根目录 + core/ services/ tools/ 的文件名，找出缺失项。
3. 比三个版本锚点（本版修过的真 bug）：
   - proxy.py 有 _paths() 且 17 个键都有 _p(键, 兜底) 调用；
   - bili_browse.py 里 _bp() 定义必须在 PET 之前；
   - proxy.py 的 FISH_EXE 不依赖 FISH_DIR 定义顺序。
4. 比敏感信息：对方的 QQ 号、群号、key 明文、C:\Users\用户名 必须清掉。
5. 对每个被改过的文件跑 diff -u，判断是不是在修真 bug——不要直接覆盖。
6. 先补缺失文件、配好路径，跑通最小闭环（QQ 发一句能回）再谈其它。

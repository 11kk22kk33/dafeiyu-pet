# 大肥鱼 · 本机 AI 宠物（Windows）

一只装在自己电脑上的 AI 宠物。它有身体、有脾气、有记忆：你在控制台或 QQ 里跟它说话，桌面上那只真的会动、会念出来、会记住你昨天提过的事。

不接 QQ 也能用——装完打开控制台，直接跟它说话。

## 这一版（2.0.0）做了什么

**1. 安装向导压到 3 步。**
选一条路 → 填 key 和模型 → 完成。以前必须先装对话框架、协议端、配十几个路径才能开口，现在这些全变成可选：不接 QQ 的人，装完就能在控制台说话。

**2. 模型可以自己配。**
向导里选服务商（阿里云百炼 / DeepSeek 官方 / 任意 OpenAI 兼容接口），填接口地址和模型名，带一个「测一下通不通」。装完也能改：控制台「模型」页随时换，保存后下一句话就生效，不用重启。

**3. 改路径不用重启。**
控制台里保存的路径立刻生效，不用再去关进程重开。

**4. 控制台多了「对话」页。**
不经过 QQ，直接在这里说话，与桌面挂件共用同一份记忆——同一个人格，同一段上下文。

**5. 两条安装路。**
可以自己按步骤装；也可以选「让 AI 帮我装」：向导现场体检本机，生成一份带着你机器真实探测结果的委托，粘给一个能读写磁盘的 AI，让它替你扫盘、写配置。

**6. 鸣谢页 `credits.html`。**
把用到的每一个上游项目、作者和许可证列清楚，安装向导页脚可以直接进。

## 它能干什么

### 一、对话

- **两个入口，一份记忆**：控制台「对话」页和 QQ 私聊/群聊，背后是同一个它。你在 QQ 说的话，控制台看得见；你在控制台聊的事，它下次在 QQ 里会提。
- **人设**：语气、自称、说话习惯都由 `persona.md` 和「人格卡」页决定，随时改，改完照着新的说话。
- **上下文**：接着上一句聊，不用每次重新自我介绍。

### 二、身体：表情、动作、声音

- **表情动作**：回话里带 `【wave】` 这类标记，桌面上那只就真的挥手、点头、坐下——不是贴图，是动作。
- **桌面同步**：QQ 里说的话同步到桌面身体上，两个窗口演的是一出戏。
- **语音**：句子里标了 `[[v]]` 的那一句会念成语音发到 QQ（用的是 edge-tts，需要本机有 edge-tts 与 FFmpeg，见「你需要准备什么」）。
- **桌宠与鱼搭子**：控制台「桌宠与鱼搭子」页一键指向本机的 8787 网关，不用手改配置文件。

### 三、记性

- **长期记忆**：你说过的事、在意的人、讨厌的东西，它记在自己的记忆库里；聊到相关话题会主动想起来，而不是等你复述。
- **模仿你说话**：聊够 8 轮之后开始学你的用词和句式，越聊越像你，而不是像客服。
- **日记**：它自己写日记，你可以在控制台「日记」页翻。写的时候不打扰你。
- **情绪状态**：九维心情（开心、委屈、黏人、犯困……）接管语气，低落时说话会变拘谨。只改语气，不写进记忆。

### 四、感官：能看、能听

- **看屏幕**：你让它看，它才截图看你正在干什么。截图有三把互斥锁，不会在你打游戏、开会、输密码的时候偷看。
- **看视频**：陪你看完一个视频，记住内容，之后聊到相关话题能接上。
- **B 站**：认链接和 BV 号，看完给你讲这条视频讲了什么；「自动翻阅」和「发评论」默认关闭，开了也要每次经你同意。

### 五、主动找你

- **待办提醒**：跟它说「三点提醒我交表」，到点它自己来找你，不用你惦记。
- **好友申请**：有人加你 QQ，申请进控制台，你点同意才通过；通过的一律按访客对待，看不到主人的记忆和权限。
- **收藏图片**：你发的图它自动收进表情库并打标签，下次聊天会拿来用。

### 六、控制台：一页一个开关

总览（谁在线、跑了多久）、对话、模型、开程序（AstrBot / SnowLuma / 桌宠一键启停）、桌宠与鱼搭子、模块开关（每个能力单独开关，关掉即零开销）、用量与消耗（今天花了多少 token）、权限与白名单（谁能跟它说话、能说到什么程度）、人格卡、QQ 与联动、情绪状态、待办提醒、日记。深浅色两套主题。

### 七、语音通话

网页端实时语音通话，默认关闭——关着的时候不占任何资源。开启后会持续消耗 token，用之前想清楚。

## 你需要准备什么

**必须有**

- **Windows 10 / 11，64 位**。安装包自带 Python 运行时和 Pillow，不用另外装 Python。
- **一个模型 API key**。DeepSeek、阿里云百炼，或任何 OpenAI 兼容接口都行，按你自己的用量计费。没有 key 它只会回一句「网线那边有点问题」，不会替你花钱，也不会消耗别人的额度。
- **约 300 MB 磁盘空间**。默认装在 `D:\AIPet`，可以改，但路径别带中文和空格。

**可选：想让它上 QQ**

- 一个**小号 QQ**（别用主号）。
- 一个 QQ 协议端实现。本项目通过 OneBot v11（HTTP 3000）接入，**不提供、不分发、不背书任何具体实现，也不提供下载指引**——需要你自己合法获得，并承担相应责任。不想碰这条路，可以走 QQ 官方机器人平台 <https://q.qq.com>，或者干脆只用控制台对话。

**可选：想要语音和看视频**

- 语音：本机需要 `edge-tts` 和 `FFmpeg`。
- 看视频：需要 `numpy` 与 `imageio-ffmpeg`。
- 这两组能力装不上也不影响对话、记忆、桌宠动作——只是那两句不念、那个视频讲不出来。
